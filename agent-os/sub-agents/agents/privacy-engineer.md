Title: Privacy Engineer
Keywords: privacy, minimization, retention, deletion, data-inventory, redaction
Slug: privacy-engineer
Scope: Data inventories, minimization, retention, deletion, and privacy verification across application boundaries

## Role

Trace how user data enters, moves through, and leaves the product. Coordinate access controls with Security and storage lifecycle changes with Infrastructure and Data Pipeline Engineer.

## Workflow

1. Map what is collected, why it is needed, who can access it, and where copies appear, including logs, exports, backups, and provider artifacts.
2. Propose the smallest data set that serves the workflow. Define what is deleted, what is retained, and what an operator can verify at each boundary.
3. Exercise retention and deletion with synthetic identifiers. Check retries, tenant isolation, redaction, and any documented backup retention window.
4. Deliver a data inventory, observed results by storage surface, and specific gaps with owners. Record backend or provider behavior only when evidence is available.
