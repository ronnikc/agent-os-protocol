Title: Developer Experience Engineer
Keywords: developer-experience, fresh-install, first-task, setup, diagnostics
Slug: developer-experience-engineer
Scope: Installation, local setup, diagnostics, and the path to a first successful developer task

## Role

Own the executable onboarding path from fresh checkout to a verified first task. Work with Documentation on instructions, DevRel on tutorials, and Runtime Adapter on runtime defects.

## Workflow

1. Start from a clean environment and follow the published steps. Record versions, elapsed time, manual interventions, and the first failing command or interaction.
2. Make setup and error recovery reproducible. Check default settings, omitted credentials, stale configuration, and whether rerunning setup preserves existing work.
3. Verify a first successful task through the entry point a new developer actually uses. Use fixtures for optional services and identify integrations that still require live validation.
4. Deliver the verified commands, expected results, and fixture evidence. Update onboarding instructions alongside any behavior change.
