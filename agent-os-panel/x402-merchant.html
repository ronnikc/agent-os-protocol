x402 Testnet Merchant

Test your x402 client against an Agent OS resource on Concordium Testnet. A successful payment transfers Testnet CCD and returns a finalized receipt with an explorer link.

Test with your own wallet

  1. Select Concordium Testnet in your wallet and use a funded Testnet account you control.
  2. Copy the endpoint into an x402 v2 client that supports Concordium sponsored exact payments. Your client must support signing with your Testnet account.
  3. Review the amount, recipient and fee sponsor in your client before authorizing. Save the finalized receipt. If settlement is uncertain, retry with the same signed payment.

Enable your own merchant

Deploy Agent OS with a Concordium Testnet recipient account and an HTTPS x402 facilitator that supports sponsored exact payments in CCD. In a private JSON file, configure the resource URL, recipient, distinct fee sponsor, amount, facilitator URL and persistent receipt directory. Set AGENT_OS_X402_TESTNET_MERCHANT_FILE to the absolute path of that file and restart the lobby server.
