x401 Proof Test

Run an HTTP x401 v0.2.0 exchange using a synthetic Agent ID. This test needs no wallet, account, or payment.

  1. The resource returns HTTP 401 with a PROOF-REQUEST header.
  2. The test client responds with a holder-bound OpenID4VP presentation. The verifier checks the issuer, holder key, resource and challenge before returning HTTP 200.
  3. The client sends the same presentation again. The consumed challenge must return HTTP 401.

Open the challenge endpoint to inspect its HTTP headers with your client.

The fixture issuer is scoped to this demo. Live interoperability with an independent verifier is a separate release check.
