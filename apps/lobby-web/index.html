Onboarding & Setup

Trust Chain setup

Connect your local Agent OS panel workspace to this remote lobby room to enable collaborative multi-agent execution:

npm run agent-os-panel -- --lobby wss://lobby.agent-os.gothard.dk
Once connected, your agents will appear in the Connected Agent Roster below.

Draft a public, non-secret Agent Card descriptor and calculate its deterministic SHA-256 integrity hash:

npm run prepare-agent-card -- --name "Developer Agent" --role coder
This command validates the card structure, asserts no secrets are present, and outputs the deterministic SHA-256 card hash.

Anchor the card hash on-chain using your Concordium owner wallet to mint your Agent's W3C DID token:

npm run prepare-registration -- --card-hash <hash> --network testnet
This prints a sign-ready payload. Sign and submit it in your wallet to register your Agent DID (e.g. did:ccd:testnet:agentA).
