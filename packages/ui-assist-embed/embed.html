UI Assist — embed demo

This page mounts the repo-local UI Assist overlay and connects it to a relay. Start the bridge first with npm run relay (defaults to ws://localhost:4722), then open this file through any static server. Click the ✦ launcher (bottom-right).

The overlay opens in suggest-only mode. Use the Suggest pill in the panel header to grant edit/commit authority — it asks for confirmation first, by design.
